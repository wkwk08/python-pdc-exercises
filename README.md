# Parallel and Distributed Computing Laboratory Activities

These activities let you explore the fundamentals of parallel computing and distributed computing through hands‑on Python exercises. Each lab demonstrates a core concept—threads for parallelism, processes for distribution, synchronization, memory access, and workflow coordination—while the machine problems extend these ideas into performance analysis and hybrid systems.

## Prerequisites
- Python 3.8+
- pip
- Virtualenv (recommended)

### Installation 

1. **Clone the repository**
```
$ git clone https://github.com/wkwk08/python-pdc-exercises.git
$ cd python-pdc-exercises
```

2. **Create and activate a virtual environment**
```
$ python -m venv venv

# Windows
$ venv\Scripts\activate

# macOS/Linux
$ source venv/bin/activate
```

#### Run 

```
$ python src\filename.py # replace w/ actual file
```
